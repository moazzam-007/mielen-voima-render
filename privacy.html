Privacy Policy

Effective Date: September 26, 2026

This Privacy Policy describes how Mielen Voima Automation Engine ("we", "us", or "our") collects, uses, and protects information when interacting with YouTube and Google services via Google Cloud APIs.

1. Information We Access and Collect

Our application accesses Google User Data solely through official Google Cloud OAuth 2.0 mechanisms. Specifically, we request access to the following YouTube scope:

  • https://www.googleapis.com/auth/youtube.upload: Used exclusively to upload and schedule automated video Shorts to our verified YouTube channel (@Mielen_Voima).

We do not collect, read, or store any personal user emails, personal messages, contacts, payment details, or unrelated browsing history.

2. How We Use Google User Data

Any Google data accessed by Mielen Voima Automation Engine is strictly used for:

  • Automating video file upload and title/tag/description metadata application.
  • Setting the video release schedule (using YouTube API's publishAt parameter).
Google API Services User Data Policy Compliance:
Mielen Voima Automation Engine's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. Data Storage and Protection

OAuth 2.0 access and refresh tokens are securely encrypted and stored within our private self-hosted automation infrastructure (n8n instance). No third parties have access to these tokens. Tokens are never transmitted to unauthorized external servers or sold to advertisers.

4. Third-Party Sharing

We do not sell, rent, trade, or transfer any Google user data or YouTube data to any third party, marketing platforms, or data brokers.

5. How to Revoke Access

You can review and revoke access granted to Mielen Voima Automation Engine at any time through the official Google Security Settings page:
https://myaccount.google.com/permissions
